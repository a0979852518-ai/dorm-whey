# 別喝我的乳清

停電的學生宿舍恐怖遊戲。直接打開網頁就能玩：**https://a0979852518-ai.github.io/dorm-whey/**

- 需要鍵盤與滑鼠，建議戴耳機。
- 開始畫面可以開啟麥克風：你發出的聲音他聽得到（只量音量，不錄音、不上傳）。

## 專案結構

| 路徑 | 內容 |
|---|---|
| `index.html` | **打包好的遊戲**（GitHub Pages 的網址就是這個檔）。不要手動改，用 `build.py` 產生 |
| `src/dorm.js` | 地圖：依平面圖用程式生成整棟宿舍（一樓大廳、樓梯、交誼廳、走廊、30 間寢室、浴廁、晒衣場） |
| `src/main.js` | 遊戲本體：畫面、玩家、劇情、對話、道具、音效、麥克風、捲毛的感知 |
| `src/logic.js` | 碰撞、視線、導航格、敵人（捲毛）的行為 |
| `src/shell.html` | 介面（開始畫面、HUD、對話框）與 CSS |
| `src/assets/` | 圖片、音效、語音 |
| `vendor/three.min.js` | three.js r128（本機測試用；網頁版走 CDN） |
| `build.py` | 把上面全部打包成 `index.html`（以及 `dist/` 裡的本機測試版） |
| `tools/glb/` | 把地圖匯出成 `.glb` 模型的工具 |

## 怎麼修改、更新網站

1. 改 `src/` 裡的檔案。
2. 執行 `python3 build.py`：會更新 `index.html`，並在 `dist/local.html` 產生本機測試版（用瀏覽器直接打開就能玩）。
3. 提交並推上 GitHub（`index.html` 也要一起推），大約一兩分鐘後網站就會更新。

匯出地圖模型：`pip install playwright numpy` 後執行 `python3 tools/glb/export.py`，輸出到 `dist/宿舍地圖.glb`。

## 一起協作的規則

- 開始改之前先 `git pull`，拿到別人最新的修改。
- 盡量分工，不要兩個人同時改同一個檔案的同一段（例如一個改地圖、一個改劇情）。
- 每次提交寫清楚改了什麼。

## 座標慣例（改地圖時會用到）

- x 往右是東、y 往上、z 往前是南（朝大門）。一樓地面 y = 0，二樓地面 y = `F`（3.35）。
- 二樓宿舍走廊的中心線在 x = `XS`（4.6）；東側寢室 201–215 由南往北，西側 216–230 由北往南。
- 地圖是一堆方塊：`S_()` 會擋人（有碰撞），`D_()` 只是裝飾。方塊名稱有意義：
  - 開頭 `空氣牆_`、`樓梯碰撞`、`斜牆碰撞`、`欄杆碰撞` 的不會被畫出來（只有碰撞）。
  - 名稱含「窗戶」的會畫成玻璃。
  - `二樓_NNN房_書桌k`、`床墊k` 等名稱被劇情與躲藏系統用到，改名前要確認。
- `src/dorm.js` 最後有一段「樓梯上來後的走道加長 4.6 m」：二樓在 x = −28.1 以東的東西在那裡統一往東移，寫在那一段**之前**的東西用移動前的座標，寫在**之後**的（例如樓梯口的雙開門、木頭擺飾）用最終座標。
